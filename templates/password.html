Password Security Guidelines

Do's

  • Use 12+ characters minimum
  • Mix uppercase and lowercase
  • Include numbers and symbols
  • Use unique passwords for each account
  • Consider a password manager

Don'ts

  • Don't use personal information
  • Avoid dictionary words
  • Don't reuse passwords
  • Avoid simple patterns (123, abc)
  • Never share passwords

Pro Tips

Use Passphrases

Combine 4+ random words: "CoffeeMountainBatteryStaple"

Password Managers

Tools like Bitwarden, LastPass, or 1Password generate and store secure passwords.

Enable 2FA

Two-Factor Authentication adds critical extra security even if passwords are compromised.
